# Nidhi's Archive — Birthday Edition 19.0

A personalised, responsive birthday archive for Nidhi's 19th birthday on 30 November 2026. Built with plain HTML, CSS and vanilla JavaScript. No backend, API or photo assets are required.

## Project files
- `index.html` — welcome screen, archive desktop and clickable folders
- `style.css` — blue scrapbook design, responsive layouts and decorative details
- `script.js` — file windows, personalised memories, compliments, predictions, hidden notes, birthday cake, comfort basket, countdown and final letter

## Run locally
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` in a browser, or install the Live Server extension and choose **Open with Live Server**.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all four files to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish, then test the link on a phone and desktop.

## Personal details included
The archive uses the details shared about your friendship: meeting in tuition, sharing pens and notes, Nidhi writing “sorry” repeatedly (described as around a hundred times, not an exact count), your gossip about other people's love stories, supporting one another through difficult phases, and the familiar feeling of reconnecting after time apart. It also includes her creative side, sketching, dancing, studies and future-doctor plans.

The letter avoids turning the difficult phases into blame. It celebrates the friendship and the way it feels familiar even after pauses.

## Birthday date
The countdown is set to 30 November 2026 in India time. On or after that date, it switches to a birthday greeting.

## Editing
Most copy lives in `script.js` inside `windowTemplates`, `compliments`, `predictions` and the secret-note messages. Keep the surrounding JavaScript template-string syntax intact when editing.
